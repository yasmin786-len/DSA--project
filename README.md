# DSA Structures Lab

A premium interactive DSA playground for learning **Stack, Queue and Linked List** operations.

## Stack
- Push
- Pop
- Peek
- Search
- Clear
- Underflow handling

## Queue
- Enqueue
- Dequeue
- Front
- Search
- Clear
- Underflow handling

## Linked List
- Insert Front
- Insert End
- Insert At Position
- Delete Front
- Delete End
- Delete At Position
- Delete by Value
- Search
- Clear
- Head / Tail / next-pointer visualization

## UI
- Yellow / amber / gold visual theme
- Animated operations
- Speed control 1–10
- Operation history
- Complexity information
- Responsive design

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
